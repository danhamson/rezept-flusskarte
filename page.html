Über das Format

Aufbau der Karte

Die Flusskarte stellt ein Rezept als Tabelle dar. Links steht je Zutat eine Zeile. Rechts folgen die Arbeitsschritte von links nach rechts. Jede Operation ist eine Zelle, die sich über die Zeilen aller Zutaten erstreckt, die sie zusammenführt. Leere Zellen ohne rechten Rand verlängern Zutaten, die erst später dazukommen.

Was die Flusskarte zeigt

  • Aufteilung: Wird eine Zutat mehrfach verwendet, bekommt jede Verwendung eine eigene Zeile mit Anteil (Teil 1/2).
  • Geräte: Ofen und Form sind eigene Zeilen. So sieht man, dass der Ofen zuerst an muss.
  • Zeit und Hitze: Dauer, Temperatur und Wartezeiten (schraffiert) stehen im Schritt.
  • Fertig, wenn: Garpunkte wie „goldbraun“ stehen direkt im Schritt.
  • Zwischenprodukte tragen Namen, Hinweise werden zu Fußnoten, Schichtungen bekommen einen Schichtplan.
  • Zeitplan für eine Person sowie eine Prüfung, die Lücken im Originalrezept findet.

Rezept teilen

Das ganze Rezept steckt in einem Code. Füge ihn in eine Nachricht, Notiz oder E-Mail ein; hier eingefügt wird daraus wieder die Karte.

Mit KI umwandeln

Die App schickt nichts an eine KI. Du kopierst einen Prompt in die Chat-KI deiner Wahl und fügst deren Antwort hier ein.

  1. Prompt kopieren und in die KI einfügen.

    Die Formatanleitung eignet sich als dauerhafte Anweisung, etwa für ein eigenes GPT, ein Gem oder ein Claude-Projekt. Danach genügt es, Rezepte zu schicken.

    Prompt ansehen
  2. Antwort einfügen: die komplette Antwort der KI, Codeblock und Begleittext dürfen dabei sein. Die KI schreibt das Rezept auch einheitlich neu (Titel, Zutatenliste, nummerierte Schritte); dieser Text ersetzt das Rezeptfeld, „Rückgängig“ holt das Original zurück.
